# Product — Flux Labs

## Positioning

Flux Labs is an **AI-powered academic operating system** for students.

It is **not**:

- An answer machine / homework chatbot
- An LMS replacement (Canvas, Blackboard, etc.)
- A generic AI wrapper
- A note-taking app alone

It **is** a persistent academic intelligence layer that understands the student and their academic environment, then helps them learn, plan, and improve.

## Core principles

1. **Learning first** — guide, teach, hint, and require participation when appropriate. Not a rigid never-answer rule; a policy engine selects the right mode.
2. **Personalization through evidence** — no visual/auditory/kinesthetic learning-style pseudoscience.
3. **Persistent context** — conversations are not isolated; student + academic context accumulate.
4. **Cost control** — server-side model selection, usage accounting, budgets, rate limits.

## V1 navigation

Home · Classes · Tasks · Calendar · Study · Resources · Progress · Settings

No vanity Analytics page — Progress is student-facing and actionable.

## V1 success criteria (target across phases)

A student can create an account, establish academic context, manage classes/tasks, receive guided AI help with persistent context, and have usage tracked safely with user isolation.

Phase 1 delivers the foundation for that loop — not the full loop.
